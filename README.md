# FjiNeko.github.io 🐾

> FjiNeko (RottanNeko) 的个人主页与开发者作品集，自动部署于 GitHub Pages。

🌐 **在线预览**：[https://fjineko.github.io](https://fjineko.github.io)

---

## 🌟 特性

- **现代化极客风格设计**：基于 Tailwind CSS + Lucide Icons + 玻璃拟态 (Glassmorphism)。
- **动态交互**：
  - 粒子连线动态背景画布 (`particle-canvas`)。
  - 动态打字机身份介绍效果。
  - 邮箱一键复制及反馈交互。
- **自适应与轻量化**：响应式适配桌面端与移动端，极速加载。
- **免额外构建依赖**：纯静态前端，可直接托管于 GitHub Pages。

---

## 🛠️ 本地预览

可以直接双击打开 `index.html`，或通过任何轻量本地服务器运行：

```bash
# Python 快速启动本地预览服务器
python -m http.server 8080
```

浏览器访问 `http://localhost:8080` 即可查看。
